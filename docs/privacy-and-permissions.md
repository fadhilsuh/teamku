# Privacy and permissions

Sensitive photo, location, identity, salary, and document values require tenant scope and explicit permission. Managers may view their department only and never receive salary fields. HR can run payroll; employees see only their own attendance and requests. Attendance evidence is private, should use short-lived signed URLs in production, and has configurable retention. The web experience records camera/location consent but cannot guarantee liveness, device binding, or fake-GPS detection.
